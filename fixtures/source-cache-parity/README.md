# Supplementary source cache parity fixture

These synthetic rows contain no patient data or copied production records.
They exercise the release source adapters for ClinVar, gnomAD, dbSNP, CADD,
phyloP, REVEL, SpliceAI, and dbNSFP.

`expected.ndjson` is authored from the declared source-field contracts. It is
not generated by fastVEP or AnnoCAT. The parity script builds both OSA1 and
OSA2 caches, fully verifies each cache, annotates `query.vcf`, and requires both
formats to equal this expected structured output.

The fixture covers:

- exact normalized allele matching and a neighboring allele with no evidence;
- multiallelic Number=A gnomAD and Number=R dbSNP values;
- transcript-scoped REVEL records;
- repeated dbNSFP exact keys and transcript vectors;
- SpliceAI record lists and signed delta positions;
- lossless SpliceAI lookup for an ambiguous-reference `N>A` key;
- allele-scoped CADD; and
- positional phyloP.

Run it with the fastVEP binary pinned by `config/fastvep-pin.json`:

```text
python scripts/verify-supplementary-cache-parity.py --fastvep path/to/fastvep
```
