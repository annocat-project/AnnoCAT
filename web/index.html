AnnoCAT

AnnoCAT is an application for annotating and reviewing genomic variants. It combines variant effects with clinical, population, conservation, and prediction data. Most annotation runs locally. Online annotation is used only when you request it.

Research use only

Do not use AnnoCAT for diagnosis or patient-care decisions. Results can be incomplete or incorrect and should be checked against the original data sources.

Phenotype features use the Human Phenotype Ontology. Condition terms use the Mondo Disease Ontology. Gene identities use HGNC. Review the HPO terms, MONDO CC BY 4.0 terms, and HGNC CC0 terms.
